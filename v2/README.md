# MotorWr 2.0 Beta

MotorWr es un proyecto comunitario no oficial para Wild Rift.

## Alcance

- Selección de campeón propio, cinco roles, cinco rivales y cuatro aliados opcionales.
- Catálogo de 146 campeones con atributos tácticos aproximados.
- Riesgo de enfrentamiento, daño AP/AD, control y lectura de sinergias.
- Build individual curada actualmente solo para Camille en Barón.
- Para los demás campeones no se inventan builds ni runas exactas: se ofrece estrategia general con advertencia de cobertura.
- Historial local, copia de guía y funcionamiento offline de los recursos principales.

## Pruebas

npm test
npm run build:v2

## Despliegue

La rama feature/motorwr-2-multichampion publica una preview independiente de producción. La rama main conserva Camille FAST v1.1 hasta aprobación.

## Datos

No existen estadísticas del servidor chino en vivo ni integración con la cuenta o el cliente del juego. Los retratos compartidos por Data Dragon de LoL PC pueden no coincidir con Wild Rift. Revisar derechos y políticas de Riot Games antes de distribución pública.
